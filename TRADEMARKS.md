# Trademarks and the cadkit name

## File-format names

"DWG", "DGN" and "DXF" are used only to name file formats. cadkit is not affiliated with,
endorsed by or certified by any CAD vendor, and it makes no compatibility certification
claims. Other names mentioned in this repository belong to their owners.

The code is licensed under MIT OR Apache-2.0; those licenses do not grant rights to the
cadkit name or logo (Apache-2.0 section 6 says so explicitly). The following uses are
welcome without asking:

- saying that your software uses, supports, or is built with cadkit;
- linking to the project with the name or the unmodified logo;
- writing about cadkit in articles, talks, tutorials and teaching material.

Please do not:

- name your product, package, crate or domain so that it looks like the official cadkit
  project (for example "cadkit-pro" or "official cadkit builds");

- suggest that the cadkit project endorses or certifies your product.

Logo files and usage notes are published at <https://cadkit.org/brand/>. Ask at
[hello@cadkit.org](mailto:hello@cadkit.org) if you are unsure.
