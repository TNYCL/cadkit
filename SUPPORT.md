# Getting help

- **Documentation:** <https://cadkit.org/docs/>. The Rust API reference is on
  [docs.rs](https://docs.rs/cadkit).
- **Questions and ideas:** [GitHub Discussions](https://github.com/TNYCL/cadkit/discussions).
- **Bugs:** [open an issue](https://github.com/TNYCL/cadkit/issues/new/choose) with a minimal
  synthetic or public sample. Never attach confidential or client drawings.
- **Security vulnerabilities:** do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Anything else:** [hello@cadkit.org](mailto:hello@cadkit.org).

cadkit is maintained by volunteers and offers no service-level guarantee. Reports with a
reduced, shareable input file get answered first.
