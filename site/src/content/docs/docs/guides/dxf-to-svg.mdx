## What the SVG contains

- The `viewBox` is in drawing units, with the Y axis flipped so the drawing is not upside
  down: SVG Y is the negated drawing Y. The `width` you choose sets the pixel size; the
  height follows the drawing's aspect ratio.
- Each layer is a `<g data-layer="NAME">` group, so a viewer can show and hide layers with
  CSS or script. Strokes use `vector-effect="non-scaling-stroke"`, so their width stays in
  pixels when the SVG is scaled.
- Layers that are hidden or frozen in the drawing are left out unless you ask for them
  (`include_hidden_layers`, `includeHiddenLayers`, `cadkit::to_svg_all_layers`).
- Block references are expanded, and text is drawn as SVG text, unless you turn either off
  (`text`, `expand_blocks`).

Models are listed in `doc.models` (Rust and Python) or `doc.info().models` (JavaScript); for
DWG and DXF, index 0 is model space and the paper layouts follow.

## Large or untrusted drawings

`to_svg` builds the whole SVG in memory. For files from other people, use the bounded variant
(`cadkit::to_svg_bounded` in Rust, `toSvgBounded` in JavaScript): it either returns a complete
SVG within the byte budget you give or fails with a limit error, never a truncated drawing.
See [Handling untrusted files](/docs/guides/untrusted-files/).
