Inspection comes in two depths. A **header inspection** reads only what the file declares
about itself: format, version, units, code page and, where the format records it, whether the
drawing is 3D and which application wrote it. It does not decode entity streams, so it is
cheap even for large files. A **full read** gives you every layer, block, model, entity and
warning.

## Header, layers, counts and warnings

## Reading the results

- **Layers.** DGN levels are reported as layers. Each layer has `visible`, `frozen` and
  `locked` flags and a colour. An entity's `layer` names its layer; entities without one
  belong to the default layer.
- **Entity kinds.** Points, lines, polylines, circles, arcs, ellipses, splines, text and
  multiline text, block references (`insert`), hatches, dimensions, leaders, faces, polygons,
  meshes, images, viewports and groups. Records a reader cannot model become `unknown` entities rather than being dropped.
- **Warnings** have a stable `code` (for example `dgn.unknown_element.type_36`), a message
  and, where known, the byte offset in the file. They mean the reader kept going past
  something it could not fully decode.
- **Format-specific data** that the neutral model has no field for is kept in `props` with a
  `dwg.`, `dgn.`, `dxf.` or `gml.` key prefix.

The full shape is in the [document JSON schema](/docs/reference/document-schema/).
