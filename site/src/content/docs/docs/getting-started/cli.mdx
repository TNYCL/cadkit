The `cadkit` binary (crate `cadkit-cli`) inspects and converts drawings from the shell or a
script. It uses the same readers and writers as the libraries.

## Install

Linux and macOS:

```sh
curl -fsSL https://cadkit.org/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://cadkit.org/install.ps1 | iex
```

The script picks the build for your platform, downloads it from `release.cadkit.org` (or from
the GitHub release when that host cannot be reached), checks it against the release's
`SHA256SUMS` and copies `cadkit` into `~/.local/bin`. On Windows it goes to
`%LOCALAPPDATA%\Programs\cadkit\bin`, which is added to your user `PATH`. No administrator
rights are needed. Both scripts are short; read [install.sh](/install.sh) or
[install.ps1](/install.ps1) before you run them.

| Variable | Meaning |
|---|---|
| `CADKIT_VERSION` | Install this version, for example `0.5.3`, instead of the latest release |
| `CADKIT_INSTALL_DIR` | Directory the binary is copied into |
| `CADKIT_NO_MODIFY_PATH=1` | Windows: leave the user `PATH` alone |

Other ways to get it:

- Prebuilt: `cadkit-<target>` archives at `https://release.cadkit.org/v<version>/` and on
  [GitHub Releases](https://github.com/TNYCL/cadkit/releases/latest)
  for `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` (static binaries),
  `aarch64-apple-darwin`, `x86_64-apple-darwin` and `x86_64-pc-windows-msvc`, with checksums
  in `SHA256SUMS`.
- With Cargo: `cargo binstall cadkit-cli` (prebuilt) or `cargo install cadkit-cli` (builds
  from source; Rust 1.88 or newer).

## Commands

| Command | What it does |
|---|---|
| `inspect <file> [--json]` | Header metadata without decoding entity streams |
| `info <file> [--warnings] [--max-warnings N] [--json]` | Format, units, models, layers, entity histogram |
| `layers <file> [--json]` | Layers with their state and entity counts |
| `blocks <file> [--json]` | Block definitions |
| `dump <file> [--json]` | One line per entity, or the full document as JSON |
| `convert <input> <output>` | Convert to `.json`, `.svg`, `.dxf`, `.dgn` or `.gml`; the output extension selects the format |
| `validate-gml <file> [--tkgm-profile P]` | CityGML structural and geometry report as JSON; exits 1 when issues are found |
| `check-dgn <file>` | Structural report of a DGN V8 file as JSON; exits 1 when it has warnings |
| `repack-dgn <input> <output>` | Repack DGN V8 streams into a fresh container without changing their contents |
| `strip-seed <input> <output> [--report]` | Copy a DGN V8 seed without its drawing content; see [Write DGN V8](/docs/guides/write-dgn-v8/) |
| `completions <shell>` | Shell completion script for `bash`, `zsh`, `fish` or `powershell` |

`cadkit help <command>` lists every flag of a command. The most used `convert` flags:

| Flag | Meaning |
|---|---|
| `--to json\|svg\|dxf\|dgn\|gml` | Output format; required when the output is `-` (stdout) |
| `--width PX`, `--model N` | SVG width in pixels and the model to render |
| `--dxf-version r12 … r2018`, `--output-codepage LABEL` | DXF version and legacy 8-bit output code page |
| `--pretty` | Indented JSON |
| `--seed FILE`, `--clear-seed-model` | DGN V8 output: the seed, and permission to clear a non-empty seed model |
| `--crs ID`, `--lod N`, `--gml-metadata-only` | CityGML output: the CRS of the coordinates (required), level of detail 0 to 4, metadata for unsupported entities |
| `--explode-inserts`, `--units UNIT`, `--layer NAME`, `--kind KIND` | Transforms before writing: expand block references, convert units, keep one layer or one entity kind |

## Global options

These go before or after the command and apply to every reader:

| Option | Meaning |
|---|---|
| `--max-input-bytes BYTES` | Refuse larger input files |
| `--max-decompressed-bytes BYTES` | Stop when decompressed data would exceed this |
| `--max-objects N` | Stop after this many records, objects or elements |
| `--codepage LABEL` | Code page (WHATWG label such as `windows-1254`) for 8-bit text when the file declares none |
| `--keep-raw` | Keep the original record bytes of every entity (large) |
| `--planarity-tolerance UNITS` | Polygon planarity tolerance for CityGML validation and DGN output (default 0.01) |

## Pipes and exit codes

An input or output of `-` reads from stdin or writes to stdout (`--to` then names the output
format). Exit codes: `0` success, `1` the drawing could not be read or written (and the report
commands above when they find issues), `2` usage error.
